# ✅ Local Chat

**Version:** `1.0`

Local Chat — базовый шаблон для создания локального UI-чата с подключаемыми AI-агентами.

Проект предоставляет готовую основу для разработки собственных агентов на базе **Chainlit, LangChain и LangGraph**. В качестве локального сервера моделей используется **Ollama**.

В текущей версии реализованы:

- UI на Chainlit;
- выбор агента при создании диалога;
- единый реестр и среда выполнения агентов;
- работа с локальными моделями через Ollama;
- память внутри текущего диалога;
- сохранение памяти после перезапуска приложения;
- история и восстановление диалогов;
- поиск информации по предыдущим диалогам;
- загрузка и чтение файлов;
- чтение текстовых файлов и PDF с текстовым слоем;
- базовый `General`-агент;
- пример прикладного `Analyst`-агента:
  - чтение CSV/XLSX;
  - базовый EDA;
  - поиск по загруженной документации;
  - формирование HTML-отчёта.

Подробное описание архитектуры и методика добавления новых агентов находятся в документации проекта.

# ✅ Установка и настройка

## 1. Создание виртуального окружения

Установку библиотек и зависимостей рекомендуется выполнять в отдельном виртуальном окружении Python.

Создание окружения:

```bash
python -m venv .venv
```

Активация на macOS / Linux:

```bash
source .venv/bin/activate
```

Для Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

Установка зависимостей:

```bash
pip install -r requirements.txt
```

---

## 2. Установка Ollama

Для работы с локальными моделями необходимо установить [Ollama](https://docs.ollama.com/quickstart).

После установки убедитесь, что сервер Ollama запущен:

```bash
ollama serve
```

По умолчанию API Ollama доступен по адресу:

```text
http://localhost:11434
```

Также необходимо загрузить модель, которая будет использоваться приложением. Например:

```bash
ollama pull qwen3-coder:30b
```

Проверить установленные модели можно командой:

```bash
ollama list
```

---

## 3. Настройка переменных окружения

В корневой директории проекта создайте файл:

```text
.env
```

За основу можно использовать `.env.example`.

Минимальная конфигурация:

```env
# Основная модель Ollama
OLLAMA_MODEL=qwen3-coder:30b

# Адрес локального Ollama API
OLLAMA_BASE_URL=http://localhost:11434

# Директория для данных приложения
APP_DATA_DIR=.local-agent-chat

# Chainlit authentication secret
# Генерируется командой:
#   chainlit create-secret
CHAINLIT_AUTH_SECRET="your-generated-secret"

# Более безопасная сериализация LangGraph checkpoints
LANGGRAPH_STRICT_MSGPACK=true
```

Секрет Chainlit необходимо сгенерировать один раз:

```bash
chainlit create-secret
```

Команда выведет строку вида:

```env
CHAINLIT_AUTH_SECRET="..."
```

Её необходимо вручную добавить в `.env`.

> Не добавляйте `.env` в Git.

---

## 4. Запуск приложения

Перед запуском убедитесь, что:

- виртуальное окружение активировано;
- зависимости установлены;
- Ollama запущена;
- выбранная модель загружена;
- `.env` создан и заполнен.

Из корневой директории проекта выполните:

```bash
chainlit run app.py
```

Для разработки с автоматической перезагрузкой после изменения кода:

```bash
chainlit run app.py -w
```

После запуска Chainlit выведет локальный адрес приложения. По умолчанию интерфейс доступен через браузер.

# ✅ Локальные данные

По умолчанию состояние приложения хранится в:

```text
.local-agent-chat/
```

В этой директории находятся данные, связанные с:

- историей диалогов;
- памятью агентов;
- поиском по прошлым диалогам;

- локальным индексом знаний;
- созданными агентами артефактами.

Эта директория является runtime-состоянием приложения и не должна добавляться в Git.

# ✅ Агенты

В базовой версии доступны два примера.

## ⭐ General

Универсальный агент для обычного диалога и работы с базовыми возможностями платформы.

## ⭐ Analyst

Пример специализированного агента для анализа данных.

Он умеет:

- работать с CSV и XLSX;
- изучать структуру выборки;
- считать базовые статистики и показатели качества данных;
- строить EDA;
- использовать загруженные PDF/TXT-документы как базу знаний;
- формировать HTML-отчёт с результатами анализа.

`Analyst` в первую очередь является примером того, как поверх общей инфраструктуры Local Chat создавать собственных специализированных агентов.
